# SaaS Review Lab

中小企業のDX担当者に向けて、法人向けSaaSの比較検討に役立つ情報を提供するメディアです。公式サイトの公開情報および公開されている第三者のレビューを調査・整理し、料金・機能・導入時の注意点を解説しています（編集部による実機検証は行っていません）。

**公式サイト:** https://solederlego8-a11y.github.io/saas-review-lab/

## コンテンツ

- [レビュー](https://solederlego8-a11y.github.io/saas-review-lab/reviews) — 会計ソフト・電子契約・名刺管理・勤怠管理などのSaaSレビュー
- [比較記事](https://solederlego8-a11y.github.io/saas-review-lab/comparisons)
- [導入ガイド](https://solederlego8-a11y.github.io/saas-review-lab/guides)

## 運営者の他サイト
